# Examples

Self-contained example knowledge bases demonstrating each organizational strategy.

All examples reference the meta entrypoint:
- [https://forgejo.example/your-org/meta-knowledge-base/src/branch/main/README.md](https://forgejo.example/your-org/meta-knowledge-base/src/branch/main/README.md)

## Examples by strategy

| Example | Strategy | Description |
|---------|----------|-------------|
| [team-handbook](team-handbook/README.md) | Handbook | Curated onboarding docs with single entrypoint |
| [research-notes](research-notes/README.md) | Atomic notes + maps | Many small notes with map-of-content index |
| [meal-planner](meal-planner/README.md) | Source-first synthesis | Canonical data files with synthesis that references sources |
| [api-catalog](api-catalog/README.md) | Metadata + views | Items with frontmatter tags/status, queryable index |

## Strategies overview

- **Handbook**: Curated documentation designed for onboarding. Single entrypoint, organized by reader need.
- **Atomic notes + maps**: Many small, focused notes with lifecycle markers. Map-of-content provides navigation.
- **Source-first synthesis**: Canonical data files are the source of truth. Synthesis documents reference sources.
- **Metadata + views**: Items have structured frontmatter. Index provides filtered views by status, tags, etc.

See [strategies documentation](../docs/strategies/README.md) for guidance on choosing an approach.
