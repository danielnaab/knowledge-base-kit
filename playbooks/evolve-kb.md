# Playbook: evolve a knowledge base

This playbook describes safe evolution without over-architecting.

## Evolution moves (low to high cost)
1. entrypoints
2. lifecycle markers ([Lifecycle policy](../policies/lifecycle.md))
3. provenance on important claims ([Provenance policy](../policies/provenance.md))
4. navigation index / map of content ([Linking policy](../policies/linking.md))
5. minimal metadata and generated views

## Anti-patterns
- inventing a taxonomy before you have content
- adding metadata nobody uses
- creating multiple conflicting sources of truth
